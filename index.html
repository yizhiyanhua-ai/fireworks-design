The philosophy

Don't ship the first draft.
Ship the verdict.

Every other tool hands you one generation and calls it done. fireworks-design runs a whole design studio in parallel — and only the page that survives exploration, judging, and adversarial refinement gets to ship.

Designed to be wrong in parallel —
so the final page is right.

A single model output is one draw from a distribution: its taste, mood, and reading of your brief are locked into that version, and its ceiling is capped by variance. We don't try to draw better. We draw many times, on purpose, and let independent critics throw out the losers.

“ Even experienced designers have to ration exploration — there's rarely time to prototype a dozen directions, so you limit yourself to a few. ”
— Anthropic, Introducing Claude Design · the shared root of the idea

Same idea. Open-sourced. Model-agnostic. Yours.

01 / BREADTH

Explore like you're infinite.

6–8 fully-committed directions, every run. One prompt gives you one mood, one taste, one lucky roll — we give you a studio's worth, then keep only what earns its place.

02 / VERDICT

Judge, don't hope.

Every direction scored 1–10 across 6 independent dimensions — hierarchy, type, color, motion, craft, delight. The winner isn't a feeling; it's a number with a paper trail.

03 / MODEL-AGNOSTIC

The model is the intern. The panel is the art director.

Inherits whatever model you run it on. A weaker model explores more crudely — but the judge-and-refine loop lifts every output toward the same bar. Bring your own intelligence.

How it works

Six phases, one shippable page

A Claude Code Dynamic Workflow — deterministic orchestration over many model agents in one JS file. No hand-holding, no single lucky roll.

① BRIEF

Distill a design system

Turn the prompt into shared tokens — fonts, palette, mood — injected into every agent after.

② DIVERGE

Explore many directions

N agents each commit to a distinct aesthetic and ship a complete page. The quality core.

③ JUDGE

Panel scoring

Every direction × 6 dimensions, scored 1–10 by independent critics. Each returns a top fix.

④ SYNTHESIZE

Graft the best

Top-3 directions read and merged into one page that must beat any single direction.

⑤ REFINE

Adversarial polish

Ruthless critique → surgical fix, looped. ClaudeDesign's "fine-grained controls," engineered.

⑥ POLISH

Ship-ready QA

Responsive, A11y, WCAG AA, reduced-motion, no broken refs — verified in headless Chromium.

FAQ

Questions, answered.

Do I need a specific model?
No. Every agent inherits your current session model. Stronger models explore more sharply, but the judge-and-refine loop lifts any model toward the same bar — that's the whole point.
How long does a run take?
Roughly 15–30 minutes for 4–6 directions. It's deliberate: ~30–50 agents explore, judge, synthesize, and polish in parallel. Quality is the point, not latency.
What do I actually get?
One self-contained final.html (single file, no build), the explored draft-*.html directions, and a short summary of which aesthetic won and why.
Can I use just one direction?
Then you don't need this workflow — run a normal frontend pass. The value is the parallel exploration + independent judging; remove that and it's just a generator.
Can I plug in my own design system?
Yes. Pass brand notes (colors, fonts, references) via the brand argument; the brief phase folds your tokens into every agent so the whole pipeline stays on-brand.
Is it really free?
MIT, open source, runs locally in your Claude Code. If it helps you ship, consider sponsoring — it funds new lenses, more examples, and ongoing polish.
